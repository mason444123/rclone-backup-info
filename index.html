rclone-backup

A personal, privately operated configuration for backing up a Linux server to its owner's Google Drive.

Backups are created and encrypted on the server with restic. rclone transfers the encrypted backup files to Google Drive using the owner's authorization. The configuration is intended for personal use; it is not a public backup service.

This website is informational only. It does not access your Google account, collect backup files, or provide a sign-in form.
