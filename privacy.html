Privacy Policy

Last updated: 13 November 2026

rclone-backup is a personal, privately operated server backup configuration. It is not offered as a public service.

Google user data and access

The server operator authorizes rclone to access their Google Drive in order to upload, list, download and remove backup files, and to maintain backup retention. The requested Drive permission may allow access to other files in that Google account; the operator controls the configuration and the authorization.

How backup data is used and stored

Restic creates and encrypts backups on the operator's server before rclone transfers the encrypted repository to the operator's Google Drive. Backup data is used for the operator's own recovery and retention purposes. The Google Drive access token and refresh token are stored in rclone's configuration on the server, with access limited by the server operator.

Sharing and service providers

Backup files are stored with Google Drive. The server hosting provider processes the server infrastructure, and this informational website is hosted by GitHub Pages. These pages do not receive Google credentials or backup data. Any sharing separately configured by the operator in Google Drive is governed by that account's settings.

Retention and revocation

Backup versions are retained or deleted according to the operator's backup settings. The operator can revoke access through Google Account permissions. Revoking access stops new uploads until access is authorized again; it does not automatically delete existing backups.

Contact

The operator can be contacted using the support email shown on the Google authorization consent screen.
